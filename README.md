# Proton

Proton is a local AI assistant designed to help with everyday computer tasks through voice or text. It combines speech recognition, local language models, text-to-speech, and a lightweight action system to understand requests and execute predefined tasks on the user's computer.

The project focuses on **local operation, low latency, reliability, and controlled actions** rather than unrestricted autonomous behavior.
The main goals while building where **To build something that is there 24/7 and doesnot require internet or any dependency except YOUR system**

### Current capabilities

* Voice and text interaction
* Local LLM inference
* Speech-to-text and text-to-speech
* Application and file operations
* Timers, system information, screenshots, and other predefined actions
* Lightweight intent/action matching
* Failure reporting and fallback to a larger model when necessary

### Goal

Build a practical **local-first personal assistant** that can eventually interact with physical systems such as Neutron.
